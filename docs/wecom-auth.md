# 企业微信登录

企业微信认证是默认关闭的内置扩展。一个部署接入一家企业自建应用，仅验证成员身份，不同步通讯录、角色、门店或业务数据。普通浏览器使用本地账号登录；扫码登录不在此模块范围内。

## 部署配置

1. 执行 `npm run db:deploy` 应用 Prisma migrations，执行 `npm run db:generate` 生成客户端。
2. 用 `openssl rand -hex 32` 生成独立的 `WECOM_SECRET_KEY`，通过部署密钥管理注入所有应用实例。不要提交该值或复用 JWT 密钥。保管备份；直接更换会使已保存 Secret 无法解密，需要重新录入 Secret。
3. 企业微信管理端创建自建应用，设置成员可见范围、应用主页、网页授权可信域名和调用 API 所需可信 IP，完成平台要求的域名归属校验。应用主页使用公开登录地址下的业务路径。
4. 超级管理员进入“系统设置 / 企业微信登录”，填写公开登录地址（例如 `https://ops.example.com`）、CorpID、AgentId、应用 Secret。公开登录地址只包含协议、域名与可选端口，不包含业务路径、查询参数或凭据；生产环境要求 HTTPS。
5. 页面实时生成授权回调地址，可点击复制。保存并校验已保存凭据，再启用企业微信登录和企业微信内自动登录。后台设置保存即生效，不需要重启服务。

回调地址为“公开登录地址 + `/api/auth/wecom/callback`”。进入授权前会跳转到此地址的 origin，再设置浏览器绑定 Cookie。反向代理需正确转发公开 Host、协议和可信客户端 IP，不能把任意客户端传入的转发头作为真实来源。多域名部署复用项目现有域名路由与 Cookie 域策略，需在各实际业务域名做跨域会话验证。

公开登录地址保存在数据库中，优先于环境变量。`WECOM_AUTH_ORIGIN` 是可选兼容默认值，仅在数据库地址为空时使用，后台保存会将表单地址写入数据库。地址变更会失效未完成的授权与绑定，旧地址的回调及绑定请求不能继续完成登录。

`WECOM_SECRET_KEY` 只保存在部署环境，本地开发可写入未提交的 `.env` 后重启服务，不提供后台编辑或回显。它是保护应用 Secret 的加密主密钥，不是企业微信提供的应用 Secret；应用 Secret 在后台配置。

凭据校验只证明 access token 获取成功，不证明可信域名、应用 AgentId、可见范围和客户端跳转已正确配置。

## 账号关联

- 管理员在账号绑定中输入准确的本地用户名及企业微信成员 UserID，可提前绑定。该操作不会同步或检索企业通讯录，管理员必须核实 UserID，不是微信号、手机号或 AgentId。
- 成员首次在企业微信打开应用，完成企业微信认证后，如未关联，会进入“关联现有账号”。输入本地用户名或手机号及密码，点击“关联并登录”。
- 身份映射一对一且不会自动覆盖。冲突由管理员核实并解绑处理；未建立账号的员工不能自动注册。
- 本地角色、门店范围、禁用和删除仍决定权限。解绑撤销该账号的全部本地会话，并失效当前待完成授权。
- 未绑定授权五分钟内有效，只能在同一浏览器完成。配置保存、预绑定及解绑会使待完成流程失效，需要重试。
- 企业微信离职状态不通过后台同步实时传播；管理员应及时禁用本地账号来撤销现有会话。

## 安全与恢复

Secret 使用 AES-256-GCM 加密，后台只回显“已配置”，不返回密文或明文。配置、绑定和解绑在审计日志以 `IDENTITY_AUTH` 业务对象记录。OAuth 和绑定使用一次性数据库凭据及浏览器 Cookie，随机凭据以带用途前缀的 HMAC-SHA-256 摘要保存；绑定接口检查 Origin 并复用数据库密码验证限流。

本地应急登录地址为 `/login?local=1`。主动退出、取消关联或未成功的授权尝试后，当前浏览器会话暂停自动登录，可点击“企业微信登录”重试。企业微信登录成功后恢复自动登录策略。停用只禁止后续企业微信登录与未完成绑定，不撤销所有已建立的本地会话；需要立即撤权时禁用对应本地账号。

## 验收

自动化测试覆盖模拟企业微信响应、绑定事务、回调重放、错误密码、冲突、禁用、配置失效、后台权限及页面流程。上线前还需使用真实企业微信完成：预绑定免登录、首次密码关联、取消与重试、退出、禁用、Secret 更新及实际域名跳转验证。测试不需要也不包含真实企业凭据。

### 本地模拟测试

CI 使用构建后的生产服务器和仅监听本机的 HTTPS 测试代理，证书临时生成并清理；测试客户端仅为该自签名测试入口放宽证书校验，应用的生产 HTTPS 校验保持启用。可用 `CI=true PLAYWRIGHT_PORT=3027 npm run test:e2e` 在完成构建后复现，需要本机 OpenSSL。

本地执行 `npm test` 和 `npm run test:e2e`。企业微信集成测试需要尚未配置企业微信的本地测试数据库，拒绝覆盖已有配置；不要对业务数据库运行测试。Playwright 为启动的测试服务器生成临时加密密钥，并由测试将本地登录地址写入测试配置，完成后清理，不需要企业微信真实凭据或 `WECOM_AUTH_ORIGIN`。不要复用缺少相同测试密钥的开发服务器，可用 `PLAYWRIGHT_PORT=3017 npm run test:e2e` 指定空闲端口。生产模式测试服务器需要 HTTPS origin。

手工检查后台时，在 `.env` 配置加密主密钥，启动开发服务，然后在后台输入如 `http://localhost:3017` 的公开登录地址。非生产环境允许 localhost、127.0.0.1 的 HTTP 地址；该地址用于本机验证配置和页面，不代表能完成真实企业微信授权。不提供可绕过身份验证的生产模拟登录入口。

### 真实企业微信联调

使用企业微信认可并完成平台要求校验的 HTTPS 域名，将流量转发至开发机服务，手机必须能够访问。后台公开登录地址填写这个域名；企业微信管理后台同步配置可信域名、应用可见范围及可信 IP。不要把任意临时隧道域名视为一定可用，也不要公开未加访问控制的调试服务。域名转发和企业微信管理端设置需要部署管理员操作，本模块不会自动创建公网入口。

企业微信接口参考：[网页授权](https://developer.work.weixin.qq.com/document/path/91022)、[获取访问用户身份](https://developer.work.weixin.qq.com/document/path/91023)。
